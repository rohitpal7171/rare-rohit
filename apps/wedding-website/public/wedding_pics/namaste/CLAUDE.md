## Replacing the Image

If a better photo is available:
1. Place the new file in this folder
2. Update the `src` reference in the component that uses it
3. Keep the old file until the new one is confirmed working in production

## Image Guidelines

- Recommended size: 800×800px minimum (displayed at various responsive sizes)
- PNG with transparent background preferred if couple is isolated
- Keep file size under 400KB — use a tool like Squoosh or TinyPNG to compress
